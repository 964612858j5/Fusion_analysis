# Regions 工具行重新设计（第五版：用户 2026-10-18 裁定后定稿，按 codex `codex_regions_tools_4.out`、`_5.out` 补全规则）

来源：用户对 R3 真机验收的第二轮意见（原话要点）：
1. viewer 上已经有 12 个各种按钮，操作太复杂，要简化；不知道要先打开 `Outlines` 才能选核心。
2. 画线、画圈改回**拖动**方式。不满意的地方是：线画完、松开鼠标、还没给经过的核心分配信息时，不能拖动和缩放。规则改为：Line / Circle 按钮点亮时不能拖动画面，但只要不是正在画，就可以缩放；只有关掉 Line / Circle 按钮，才能拖动加缩放。
3. 做一个 **Select 家族**（参考 Photoshop / Illustrator）：点 Select 弹出下拉，里面有普通单选、矩形框选、圆形框选、多边形框选（手动逐点，像画 ROI）。平时点击只单选；按住 Ctrl + 左键多选。框选只选中范围内的核心。有了多选，就可以先选好几块，再点 Merge。
4. Circle 恢复拖拽：按下一点、拖出圆；事后可以用 Select 选中，再调位置和大小。
5. 按钮归类：
   - Polygon、Circle、Vertex 都是直接生成核心的轮廓（mask），归为 **Mask / Generate**，点一下弹出下拉，选形状再画；
   - Line、Clicks 归为 **Label / Annotate**；
   - Undo / Redo 改成像 Word 那样的图标，不要文字；
   - Select 功能明确以后，`Outlines` 开关就不需要了；
   - Prev / Next 不知道是做什么的。
6. 锁定的问题先不管。

## 0. 哪些是用户要求、哪些是新增提案
- **用户要求**：
  - 6 个控件，三个下拉家族（Select / Mask / Annotate）；
  - Line、Circle 用拖动画；
  - Line / Circle 点亮时不平移，没在画时可以缩放；关掉才能平移；
  - Ctrl + 单击多选；矩形 / 圆形 / 多边形框选；
  - 先多选再 Merge；
  - 撤销 / 重做用图标；
  - 去掉 `Outlines`；
  - 锁定暂缓。
- **新增提案**（需要用户点头，见 §8）：
  - Select 单击模式下，在空白处拖动是否平移；
  - Delete 一次删多个；
  - 框选按中心判断；
  - 去掉 Prev / Next；
  - 不加"空格临时平移"。

## 1. 新的工具行（6 个控件，原来 12 个）
```
[ ⬚ Select ▾ ] [ ✎ Mask ▾ ] [ # Annotate ▾ ] [ Merge ] [ ↶ ] [ ↷ ]
```
- **Select ▾**（下拉）：
  - `Click`：单击选中，Ctrl + 单击加选或取消；
  - `Rectangle`：拖出矩形框选；
  - `Ellipse`：拖出椭圆或圆框选；
  - `Polygon`（多边形框选）：逐点单击，回车或双击闭合，框选。
- **Mask ▾**（下拉）：
  - `Circle`：按下定圆心，拖出半径；
  - `Polygon`：逐点单击，回车或点回起点闭合；
  - `Vertex`：拖动选中形状的单个顶点。
- **Annotate ▾**（下拉）：
  - `Line`：拖出一条线，按线编号；
  - `Clicks`：按顺序单击编号。
- **Merge**：一个动作按钮，不是工具。把当前选中的几块合并成一个核心，选中少于两块时不可用。
- **↶ / ↷**：撤销 / 重做，只显示图标，鼠标停上去显示文字和快捷键（Ctrl+Z / Ctrl+Shift+Z）。
- **去掉**：`Outlines`（轮廓一直显示）、`Prev` / `Next`（见 §5）。
- 下拉按钮显示**家族名加当前子工具**，例如 "Select: Rectangle ▾"、"Mask: Circle ▾"。
  - 你说的是"点按钮弹下拉"。提案是把按钮分成两部分（待用户定，§8 第 5 条）：
    - 点按钮主体：点亮或关掉这个家族，用当前的子工具；
    - 点 ▾：弹出下拉换子工具，换完自动点亮。

    另一种做法是整个按钮一点就弹下拉、在下拉里选子工具，没有单独的"关掉"。
  - 多边形框选在下拉里叫 "Polygon"（和 Mask 的 Polygon 区分开，写作 "Select: Polygon"）。
- 每个按钮和子工具都有提示文字说明用法；光标形状随工具变化；提示区显示"已选中 N 块"，以及 Merge 不可用的原因。

## 2. 模式与鼠标规则
**事件处理**：工具点亮时，从**左键按下那一刻起**，这一整次拖动（按下、移动、松开）都交给工具，所以画面不会平移（Select 单击模式在空白处拖动是例外与否，待用户定，§8 第 1 条）。滚轮在没有按住左键时一律交给画面缩放。"默认没有工具点亮"也是提案（§8 第 5 条）。

- **没有工具点亮**（默认；再点一次已点亮的按钮就关掉；Esc 逐级退到这里）：左键拖动 = 平移；滚轮 = 缩放；单击没有作用。
- **Select 点亮**：
  - `Click`：
    - 单击选中一块，Ctrl + 单击加选或取消，点空白处清空选择；
    - **按住 Ctrl 时一律当作选择**，不会触发移动或缩放；
    - 只选中一块时显示 8 个拖动点：在这块上拖动 = 移动，拖拖动点 = 缩放；
    - 选中多块时只高亮，不能拖动修改；
    - 在空白处拖动：待用户定（§8 第 1 条）。
  - `Rectangle` / `Ellipse`：拖出框，拖动过程中实时高亮会被选中的块；松开后选中。不按 Ctrl 是替换原来的选择，按住 Ctrl 是加选。
  - `Polygon`（多边形框选）：逐点单击，回车 / 双击 / 点回起点闭合后选中；Ctrl 规则同上。
- **Mask 点亮**：
  - `Circle`：按下即圆心，拖出半径，松开生成；
  - `Polygon`：逐点单击，回车 / 点回起点闭合；退格删上一点；
  - `Vertex`：编辑**已有**轮廓。只选中一块时显示它的顶点，拖顶点修改。
- **Annotate 点亮**：
  - `Line`：按下拖出线，松开后线留在图上，等你在左栏确认编号。
    - **只在拖线过程中**（左键按住）滚轮调选取带宽度；松开后滚轮恢复缩放。
    - 线留在图上时，单击某个核心 = 把它加入或移出这条线；超过拖动阈值的拖动 = 重新画一条线。
  - `Clicks`：按顺序单击，回车结束。
- 其他绘制动作在拖动过程中忽略滚轮（不缩放，也不调宽度）。
- **Esc**：每按一次只处理下面最前面一个适用的层级，按顺序是：
  1. 取消正在进行的动作（画到一半的线 / 圈 / 多边形 / 框），已改的几何回滚；取消以后，接下来的松开不会再提交；
  2. 取消还没确认的 Line / Clicks 预览，Confirm 变灰；
  3. 清空选择；
  4. 关掉工具。
- **快捷键范围**：Delete、Esc、回车、退格、撤销 / 重做只在大图一侧有效（沿用现有做法），不影响左栏的搜索框、备注、编号输入框；在大图上按下鼠标时，焦点切到大图。

## 3. 选择与合并
- **选中的单位是"组织块"**（`piece_id`）：高亮、框选、Delete、拖动点都针对块，不再整颗核心一起高亮。Exclusions 标签页里选中的单位是排除区。
- **框选**：按块的面积重心判断是否落在框里，刚好在边界上的也算。待用户定（§8 第 4 条）。
- **Delete**（多选时一次删多个，一步撤销全部恢复）：
  - 核心块：标为"不纳入"，这块就脱离了它的核心。如果这是核心的最后一块，这个核心就没了，它的位置变回"未对应"——**这不等于把整颗核心标为"排除"**；整颗排除仍用表格里的 `Exclude…`。
  - 排除区：删除。
- **Merge**（选中 ≥ 2 块）：按块**所属的核心**来判断，不按块数。
  - 涉及的已编号核心（带位置编号或自定义编号）**只有一个**：它就是接收的核心，保留原来的内部编号、位置绑定、位置上的质控 / 跑的勾选，以及自定义编号。其他选中的块并进来。
    - 带**位置编号**的：确实有新块并入时，标为"待复核"（沿用现有规则）；
    - 带**自定义编号**的：保留自定义编号，仍是"信息待补全"，不新增"待复核"规则。
  - 涉及的核心都没有编号：并进其中一个已有的核心（选中块最多的那个；一样多时取最先选中的）。都是未归属碎块时，新建一个核心。
  - 涉及**两个以上的已编号核心**：拒绝，提示"先去掉多余的编号"。
  - 选中的块本来就全属于同一个核心：什么也不做。
  - 只移动选中的块；没选中的块留在原来的核心里。
  - 整次合并是一步撤销（在现有 `merge` / "待复核"规则上做，不新增机制）。

## 4. 标签页
- **Exclusions**：
  - 同一个工具行：Mask 画排除区，Select 选排除区，Annotate 和 Merge 灰掉；
  - 选中多个排除区时，原因 / 通道 / 备注暂不能改（避免一次改好几个，或误改"下一个排除区"的默认值）；只选一个时和现在一样可以改。
- **Cores / Channels**：工具作用于组织块；ROI 工作区里核心只读。
- 切换标签页时：取消未完成的动作，清空选择；切到 Exclusions 时，点亮的 Annotate 会被关掉。

## 5. Prev / Next
- 原来的作用：按位置号跳到上一个 / 下一个**已编号**的核心，大图居中显示。
- 建议从工具行去掉；改为点核心表的某一行就跳转（已有）。另外可选：键盘 PageUp / PageDown 做上一个 / 下一个。请用户定。

## 9. 用户裁定（2026-10-18）与定稿规则（本节优先于前文）
用户原话（2026-10-18）：
1. Esc 每按一次退一步，改为 Ctrl+Z 每按一次退一步，但是不关掉工具；
2. "选中的单位是一块组织"没看懂，请通俗解释；
3. 合并涉及两个以上已编号的核心时，合并后用所有核心中最小的编号；
4. Select 单击时在空白处拖动可以平移；同意"按住空格临时平移"；
5. 同意去掉 Prev / Next；同意块的中心落在框里就算；
6. 整个按钮一点就弹出下拉；打开页面时默认不点亮任何工具；
7. 删除就是把选中的 mask 或画的区域删掉，是消失，而不是变红。

### 9.1 已定规则
- **Ctrl+Z 逐步后退，从不关掉工具**（取代 §2 的 Esc 四级顺序）。每按一次，只处理下面最前面一个适用的层级：
  1. 取消正在进行的动作（拖到一半的移动 / 缩放 / 顶点用现有的 `cancel_drag` 回滚；画到一半的线 / 圈 / 多边形 / 框直接丢弃），这一次之后的松开鼠标会被吃掉，不会再提交；
  2. 取消还没确认的 Line / Clicks 编号预览；
  3. 撤销上一步编辑（`DraftHolder.undo`）。

  工具行的 ↶ 按钮行为相同。Ctrl+Shift+Z / ↷ 只重做已提交的编辑，被取消的动作和预览不能重做。快捷键仍只在大图一侧有效；在大图上按下鼠标时，焦点切到大图。
- **Select 单击模式下，在空白处拖动 = 平移**（其他工具点亮时仍不平移）。
- **按住空格临时平移**：
  - 大图一侧记录空格是否按住；
  - 在**按下鼠标那一刻**空格已按住，这一整次拖动（直到松开鼠标）都是平移，中途松开空格也不改；工具在这一次里不收到点击；
  - 松开鼠标后回到原工具。
- **去掉 Prev / Next**；框选按块的面积重心落在框里判断，刚好在边界上的也算。
- **整个按钮一点就弹出下拉**，选中子工具即点亮这个家族。打开页面时没有工具点亮。
- **合并时涉及两个以上已编号核心：用最小的编号。**
  - "最小"按**位置号**（数字）比较，不按内部的位置标识。
  - 接收者 = 位置号最小的那个核心：保留它的内部编号、位置编号、该位置上的质控和"跑"勾选；确实并入了新块时标为"待复核"（现有规则）。
  - 其他已编号核心：
    - 选中的块并入接收者；
    - 它们原来的位置被**释放**：图上所见改为"未确认"（`observed` 清空、缺失原因清空），质控和原因**保留**（那是对这个位置的判断）；
    - 释放位置上的"跑"勾选**清除**，否则它会因为"勾了跑却没有核心"挡住锁定；
    - 没被选中、留在原核心里的块，所在核心变成"未编号"。锁定时仍按现有规则拦下，由用户处理。
  - 自定义编号：有位置编号的核心参与时，自定义编号让位，被清掉；全部都是自定义编号时，保留按字母排序最小的那个，其余清掉。
  - 只涉及一个已编号核心、或都没编号时，按 §3 处理。
  - 整次合并用一次 `DraftHolder.do` 完成，一步撤销恢复所有被改动的字段。
- **Delete = 删除**（不再变红）：
  - 选中的核心块从文件里**删掉**，同时从所属核心的块列表里去掉；
  - 核心还剩别的块时，如果有位置编号，标为"待复核"；
  - 删掉的是最后一块时，核心也删掉，它的位置释放（规则同上：图上所见清空；质控保留；"跑"勾选清除）；
  - 排除区：删掉；
  - 一次删多个，用一次 `DraftHolder.do`，一步撤销全部恢复；
  - 只改 Regions 的标注文件（照常自动保存），**不碰** F2 的候选列表文件；剩下的块的候选编号不变。
  - 删掉的未归属碎块不再挡住锁定；没删的未归属块照旧会挡住。
  - 块编号不再重复使用（范围：同一条版本线内）：
    - 文件里记一个已用到的最大块号 `piece_counter`，新画的块从它往上编；
    - 它随草稿保存，也写进锁定版本，"基于此版修改"时一并恢复；
    - 撤销会连同它一起恢复（它是草稿的一部分）；
    - 旧文件没有这个字段时，按文件里现有的最大块号补上；
    - "找核心"替换会按候选重建所有块（块号取候选编号），之后计数取两者中的较大值，所以新画的块不会和重建出来的块撞号。替换前的块号本来就全部清空，因此替换前后同号不算重复。
  - 旧数据里已有的"不纳入"标记照常读取、照常显示；右键仍能"恢复"或直接删除。
- **"找核心"替换**：只要文件里已经有 TMA 部分（选过对应表、找过核心），无论现在还剩几块，替换前都要确认，并说明"会用新的候选重建所有核心，编号和位置标记清空，排除区保留"。

## 10. 第二轮真机反馈（用户 2026-10-18）与方案（本节优先于前文）

### 10.1 用户反馈与裁定
1. Mask 的 Circle：按下的点是固定角，拖到的点是对角（像 Photoshop 椭圆选框）。裁定：画的是椭圆，按住 Shift 变正圆，按住 Alt 改成从中心往外画。
2. 已画好的形状调整大小，要和 Photoshop 的 Ctrl+T 一模一样。裁定：
   - 拖角点默认**自由**缩放，按住 Shift 保持比例；
   - 拖四条边中间的点只改一个方向；
   - 拖动时对面的点固定，按住 Alt 以中心为基准；
   - 鼠标在角点外侧拖动是旋转，按住 Shift 每次转 15°；
   - 按住 Ctrl 拖角点：只动这个角（自由扭曲）；
   - **回车确认、Esc 放弃**。
3. Merge 改成下拉，由用户选择：
   - "只改归属"：现在的做法，几块归到同一颗核心，轮廓不变；
   - "融合轮廓"：几块的轮廓合成一块新的（例如给 Find cores 识别不全的核心打补丁）。
4. Polygon 打点（Select 和 Mask 都有）要和 Photoshop 一样灵敏。
5. 在 Cores 标签页手动画的形状，画完就应该是黄色，和 Find cores 生成的一样（现在是灰色）。

### 10.2 原因
- 第 4 条：现在松开鼠标时才打点。按下和松开之间鼠标移动超过 4 个屏幕像素，这次就算"拖动"，点丢失。另外，鼠标每动一下都会重画全部轮廓，核心多时会卡。
- 第 5 条：手动画的形状是"未归属的碎块"，所以显示灰色虚线。

### 10.3 方案
- **打点**：Polygon（Mask 和 Select 两种）在**按下**时就打点，不看移动距离（Photoshop 多边形套索同样是按下打点），这次按键的松开不再做任何事。
  - Qt 的双击事件会代替第二次按下：已有 ≥3 个点时闭合；否则当作一次按下，照常打点。
  - 鼠标移动时只重画预览层（正在画的多边形、选框、圆的预览），不重画全部轮廓。
- **颜色**：在 Cores 标签页画完的形状，立即成为一颗新的、没有编号的核心（黄色，和 Find cores 的一样）。
  - 合并规则照旧：它没有编号，和有编号的核心合并时归到有编号的那颗；它变空后自动删除。
  - Find cores 结果里面积不到一半核心的小碎块，仍是灰色虚线（不变）。
- **Circle**：按下点和拖到的点构成一个框，画框内的椭圆；Shift 变正圆（取较长边），Alt 以按下点为中心。
  - 菜单里仍叫 `Circle`，提示文字写明用法。
  - 椭圆存成 64 边形，和以前的圆一样。
- **变换（Select: Click 下选中一个形状）**：
  - 形状四周显示变换框：4 个角点 + 4 个边中点；框内拖动 = 移动；角点外侧约 20 个屏幕像素内拖动 = 旋转。
  - 内部表示：框的 4 个角（初始为形状的外接矩形），形状 = 从原外接矩形到当前四边形的透视变换作用在原顶点上（OpenCV `getPerspectiveTransform`）。移动、缩放、旋转、扭曲都只改这 4 个角。
  - 缩放在框自己的方向上计算（旋转后仍沿框的边）：
    - 角点：两个方向独立缩放，Shift 保持比例；
    - 边中点：只改一个方向；
    - 默认对面的角 / 边固定，Alt 以框中心为基准。
  - 旋转绕框中心，Shift 让总角度吸附到 15° 的倍数。
  - Ctrl + 角点：只移动这个角。
  - **挂起的变换**：第一次拖动就开始一次变换，之后的拖动都在同一次变换里累加。
    - 回车确认：整次变换算一步撤销；
    - Esc 放弃：形状恢复原样，工具不关；
    - 变换中按 Ctrl+Z：退回上一次拖动，退到头就结束这次变换（形状没变）；
    - 其他操作会先自动确认当前变换：选中别的形状、换工具、换标签页、Delete、Merge、Lock、切换版本、关闭页面。
    - 变换中的形状以虚线框表示"还没确认"，提示栏写"回车确认，Esc 放弃"。
  - 鼠标光标：框内为移动光标，角点、边中点为对应方向的缩放光标，旋转区为旋转光标。
  - 只读版本和 ROI 工作区里的核心一律不能变换（规则同前）。
  - Vertex 工具不变。
- **Merge 下拉**：按钮改成 `Merge ▾`，有两项：
  - `Group (same core)`：现在的做法；
  - `Union (fuse outlines)`：把选中的块栅格化后合成一个轮廓（`cv2.fillPoly` + `findContours` 外轮廓，内部空洞填满）。
    - 要求连成一片：合成后只有一个外轮廓才执行；否则提示"这几块不接触，不能融合；只想归到同一颗核心请用 Group"。
    - 结果是一块新的组织块（新块号，来源记为 `union`），原来的块删除；
    - 新块归属按 Group 的同一规则（最小编号保留、其余释放，释放前弹框）；
    - 接收核心里没被选中的块保留；一次撤销恢复全部。
  - 两项在 Exclusions 标签页都不可用（保持现状）。

### 10.5 按 codex 方案审查修订（`codex_regions_plan10_1.out`，修改后批准）
- **挂起的变换不写进文档**（取代 10.3 里"开始时 begin_drag"的做法）：
  - 变换状态（原顶点的浮点副本、当前四边形、每次拖动后的四边形历史）只存在页面上，图上画的是预览；文档里还是原来的形状。
  - 回车 = 一次普通的 `page.edit(set_polygon)`，照常一步撤销、照常自动保存；Esc = 丢掉状态。
  - 所以自动保存、`DraftHolder.do`、锁定、切换版本都看不到"没确认的形状"；漏掉某个自动确认的入口，最坏只是丢掉预览，不会写坏文档。
  - 自动确认的入口：
    - `page.edit`（所有普通编辑：编号、Run / 缺失 / 质控、右键菜单、排除区字段、Find cores 结果、Delete、Merge、新画的形状）；
    - 选择改变（单击、Ctrl 点击、框选、表格行）、换工具、换标签页；
    - Lock / 基于此版修改、切换版本、`set_context`、离开 Regions 页（`hideEvent`）、`shutdown`。
  - Discard draft：确认丢弃后丢掉变换；取消对话框则保留。
- **变换中的键**：
  - 回车确认；
  - Esc 放弃并保留工具（再按一次 Esc 才关工具）；
  - Ctrl+Z：拖动中先回到这次拖动的起点；松手后退回上一次拖动，退到头就结束这次变换（不碰文档的撤销历史）；
  - ↷ 在变换中不可用。
  - 被变换接管的松开不再当作单击（不会改变选择）。
- **变换的数学定义**：
  - 每次预览都从原顶点（浮点、未裁剪）重新计算：原外接矩形 → 当前四边形的透视变换。
  - 提交时沿用现有规则：逐顶点取整、钳位到切片内（不做多边形求交）。
  - 框有一个方向角 θ（从 0 开始，只有旋转会改变它）。
  - 缩放在 θ 的坐标系里对 4 个角统一做仿射缩放：p' = a + R(θ)·diag(sx, sy)·R(−θ)·(p − a)；扭曲之后同样适用。a 是对面的角或边中点；按住 Alt 时 a 是四角的平均点。
  - 缩放倍数按这次拖动开始时的四边形计算，不逐帧累乘。
  - Shift 保持比例时，倍数取指针在对角线方向上的投影。
  - 允许翻转，但倍数绝对值太小或四边形自交时，保留上一个有效结果。
  - 旋转绕四角平均点；Shift 让 θ 吸附到 15° 的倍数（θ 不受扭曲影响）。
  - Ctrl + 角点：只移动这个角；四边形必须保持凸、不自交，否则保留上一个结果。
  - Ctrl 按在变换框的角点上 = 扭曲；其他位置的 Ctrl + 单击仍是加选 / 减选。
  - Shift / Alt 在拖动过程中随时生效（鼠标移动事件也带上修饰键）。
  - 确认后再次变换，框重新取外接矩形（方向不保存）。
  - 不加 Ctrl+T 快捷键：选中一个形状就出现变换框。
  - 注：部分 Linux 桌面会把 Alt + 拖动用来移动窗口，真机验收时留意。
- **Union**：
  - 先算几何，再在一次 `holder.do` 里完成：
    - 新块先加进接收核心；
    - 再从各自的核心里去掉被选中的块；
    - 其他核心按 Group 的规则释放；
    - 接收核心保留它的 UID、编号、质控和 Run，如果有编号就标为待复核；
    - 同一颗核心里的几块也可以 Union（Group 在这种情况下什么都不做）。
  - 新块：新块号，`source = "union"`，记录来源块号，`candidate_id` 和 `tissue` 为空（不冒充测量值）。
  - 连通规则：栅格化后按 4 邻接只有一个连通区域才执行；否则提示"不接触"。不使用 keyhole 兜底。
  - 外轮廓用 `approxPolyDP`（误差 1 像素）简化顶点。
  - 合成范围超过 1 亿像素时拒绝，提示"相距太远"。
- **重画**：
  - 静态轮廓画进缓存图，只在轮廓或视野变化时重画；
  - 鼠标移动、加点只更新预览层（`_polygon_click` 也改为只刷新预览）。
- 测试：
  - 两种 Polygon 用真实事件走"按下 → 移动超过 4 像素 → 松开"，必须恰好加一个点；
  - 多次拖动后一次确认或撤销；
  - 确认前有自动保存计时器，Esc 后重开不恢复；
  - Lock / 切换版本 / 切换工作区前自动确认；
  - 旋转后缩放、扭曲后缩放、切片边缘的形状；
  - 同一颗核心的 Union、接收核心的块全部被替换、环形孔洞、对角接触。
- 补充（实施审查 `codex_regions_impl10_1.out` 之后）：
  - 按住 Shift 拖边中点：两个方向按同一倍数缩放（Photoshop 也是这样）；不按 Shift 时只改一个方向。
  - 按在手柄附近时记下"手柄位置减去指针位置"的偏移，只按下不移动不会改变形状。
  - 旋转热区落在另一个形状上时，让位给那个形状的单击。
  - 变换中的形状不进缓存层，单独画，拖动时不重画全部轮廓。

### 10.6 Circle 的起点（用户真机验收 2026-10-18）
- 用户：其他部分验收通过；只有 Circle 不满意，起点必须固定，现在会随着鼠标越拖越远而移动。
- 原因：原来的做法里，按下的点是框的一个角，椭圆画在框里面，并不经过这个点；框越大，轮廓离起点越远（正圆时约为半径的 0.29 倍）。
- 改为：按下的点和鼠标所在的点都在轮廓上，两点是对角关系。椭圆经过以这两点为对角的矩形的四个角（中心在两点中点，两个半轴为矩形半边长的 √2 倍）。
  - 按住 Shift：以两点连线为直径的正圆；
  - 按住 Alt：按下的点是中心，鼠标所在的点在轮廓上。
