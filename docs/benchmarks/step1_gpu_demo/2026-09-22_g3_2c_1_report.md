## 三、做法

1. **点序与身份先核对，不猜。** Step0 的 `polygon_fullres` 是 `(x, y)`、`bbox_fullres` 是
   `(y0, y1, x0, x1)`——用用户 20:20 那份 ROI 实测确认（x∈[4320,16992]、y∈[640,11104]
   与 bbox 逐值相同，绕向为顺时针）。
   `sanitize_roi_polygon()` 要求**多边形自身的包围盒等于当前 ROI 矩形**（容差 1 px），
   所以另一个 ROI 的旧多边形不可能被贴到这个来源上；`ViewportSnapshot` 每次提交重新冻结，
   A→B→无 ROI 之后不留旧 mask（有门）。
2. **奇偶填充，不是实心扇形。** 三角扇 + `GL_INVERT` 写 stencil 低位：
   凹多边形的缺口被覆盖偶数次因而留空。
   **`step1_gpu.vert` 只能产生固定的全屏三角形**（它用 `gl_VertexID` 造顶点），
   所以新增了独立的 `step1_gpu_mask.vert/.frag` 与自己的 VAO/VBO。
3. **stencil 只挂在 `final` FBO 上**，尺寸跟随物理输出，创建后检查 FBO 完整性，
   随目标重建与销毁一起释放。每次提交：scissor 关闭下清颜色 + stencil → 写多边形 mask →
   现有 finalize pass 同时受 **stencil 与 bbox scissor** 限制。
4. **状态一律归还**（`_restore_clip_state()`）：scissor、stencil 测试/写掩码/函数/op、
   颜色写掩码，**包括"区域完全离屏"的提前返回路径**。
5. **给了坏多边形不当成"没有多边形"**：`sanitize_roi_polygon()` 返回原因，
   `submit()` 的统计里带 `roi_polygon_error`，`layer.roi_polygon_error()` 可读，
   矩形裁切继续生效（画面仍被 bbox 约束，不会泄到矩形外）。

## 五、门（**22 条**新增，全部读真实 framebuffer）

每条同时断言三件事：多边形外 alpha=0；多边形内与"同一提交但不裁"的画面逐像素相同；
**未裁切的那一帧确实在多边形外画了东西**（否则该用例不能证明任何事）。

覆盖：**明显凹陷的缺口留空**（奇偶 vs 实心扇形的判别门）、顺/逆时针、
coarse-only / fine-only / 混合、raw DAPI 单通道 / Overlay / Fusion、
平移 / zoom-out / 非整数缩放、**DPR 1.0 / 1.5 / 2.0**、resize 后 stencil 重建、
ROI 完全离屏、**A→B→清除后无残留 mask**、只有 bbox 没有多边形时维持 G3.2c 行为、
**坏多边形被明确拒绝并报告**、**GL 状态归还**（正常路径与离屏提前返回各一条）、
以及**用户那份 9 点真实 ROI**（按多边形而非 bbox 统计，并断言 bbox 与多边形之间确有面积）。
产品路径门另增一条：多边形从 handoff 经 `_active_roi` 到 `ViewportSnapshot` 再到 GPU，
点数与坐标逐点相同，且 FBO 多边形外为 0。

**本轮修掉的三处问题（如实记录）：**
1. **代码真 bug**（被状态门抓到）：区域完全离屏的提前返回把 `glStencilMask(0)` 留给了下一帧。
2. 我给产品路径门加的一次"补提交"用了历史里的 descriptor，测的是产品从未画过的帧，已删。
3. **offscreen 下 `grabFramebuffer()` 不是可信证据**：同一夹具里它一次返回**全部 496 958 像素非黑**
   的未初始化显存、下一次返回 60 %，而 FBO 两次都精确等于区域。
   用阈值区分"垃圾帧与真帧"同样脆弱，因此**离屏门只断言 FBO**，
   合成画面的证据改由**真实显示器**上的窗口截图提供（见第四节）。

## 七、限制

1. **首版只支持单个无孔洞的简单多边形**；自交、多环、带孔输入**不声称支持**，
   也不静默近似——不满足身份校验的一律被拒并报告。
2. **边缘像素规则：** 与 bbox 裁切一致，按**像素中心**判定（stencil 的光栅化规则），
   不做羽化。**与 Step0 的多边形掩膜可能相差约一个像素**：Step0 用 `cv2.fillPoly` 在
   level-0 网格上填充，本块在**屏幕像素**上光栅化同一多边形，两者的边界取舍规则不同；
   门用"膨胀/腐蚀一像素"的严格内外来判定，正是为了不把这一像素之差当成缺陷。
3. **CPU fallback 未改**，其边界行为与从前相同。
4. **不得记为真机通过。**
