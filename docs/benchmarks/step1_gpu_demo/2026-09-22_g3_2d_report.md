## 二、G3.2c / G3.2c.1 生产 diff 复核（`+335 / -4` 行，两个文件）

| 复核项 | 结论 |
|---|---|
| ROI 身份与 polygon 不错配 | `sanitize_roi_polygon()` 要求**多边形自身包围盒 == 当前 ROI 矩形**（±1 px），否则拒绝并上报；`_gpu_roi_world_rect` 每次提交从**活的** source table 读，不用全局缓存 |
| A→B→无 ROI 不留旧 mask | 每次 `_finalize` 在 scissor 关闭下**同时清颜色与 stencil**；门 `test_roi_a_then_b_then_none` 断言清除后画面与"从未裁切"逐字节相同 |
| 空交集（区域完全离屏） | 提前返回前调用 `_restore_clip_state()`；门 `test_the_off_screen_path_also_restores_state` |
| resize | stencil renderbuffer 随 `_ensure_targets` 重建并检查 FBO 完整性；门 `test_a_resize_rebuilds_the_stencil` |
| 销毁 | `_destroy_targets` 删除 stencil RBO，`_destroy_gl_names` 删除 mask VAO/VBO 与程序 |
| **错误路径** | **本块复核中发现缺口并修复**：restore 原本在 draw 之后，且 `try` 起点晚于 mask 写入——mask 阶段或 draw 阶段抛错会把 scissor/stencil/颜色写掩码留给下一帧与 `paintGL` 的 blit。现改为**从第一次状态改动起就在 `try/finally` 内**；新增门 `test_a_failure_while_clipping_still_hands_the_state_back`（注入 `_draw` 失败）。该门在修复前为红。 |
| CPU fallback | 未改；**新增限制门** `test_the_cpu_fallback_has_no_polygon_clipping`，断言 `Step1ComposedLayer` 不接受 polygon 且 `_start_cpu_backend` 不涉及 polygon——把"本块不覆盖 CPU 路径"写成可执行事实 |

## 四、Blocker / Advisory

**Blocker（本块不修，已知且未解决）**
1. **G3.2b.5A 画 Patch 时主 Viewer 短暂晃动**：真机录像证实存在（四次新建 Patch 各一次
   ~67–100 ms 全幅瞬变后逐位复原），台架始终未复现，**根因未定**。诊断线保持暂停；
   **不得因为某次"没出现"就宣称已修**。

**Advisory（限制，非缺陷）**
2. **Step1 入口 GUI 心跳曾记录 1712 ms 间隔**。用户主观验收为"不到 1 秒、不卡住"，
   但该测量值保留为性能 advisory。
3. **多边形裁切首版**：只支持**单个无孔洞简单多边形**；自交/多环/带孔一律被**拒绝并上报**
   （不静默近似）。边界按**像素中心**判定、不羽化，与 Step0 的 `cv2.fillPoly` 掩膜
   **可能相差约一个像素**。
4. **CPU fallback 不做多边形裁切**（已写成门）。GPU 起不来时，raw 通道仍画到 ROI 矩形。
5. **持久化 coarse 只对带 `source_identity` 的新产物生效**；用户现有旧产物仍走运行时归约，
   显式补建脚本从未在真实项目上运行过。
6. **`TileScheduler.shutdown()` join** 在用户切片上曾由 1.3 ms 升到 329 ms（demo 无此变化），
   原因未查清，未改代码。

## 五、面向用户的最终真机清单（只列**尚未**逐项验收的公开操作）

> 已通过的不再重做：G3.2c 的 bbox 裁切、G3.2c.1 的多边形轮廓裁切、
> G3.2a 系列交互、G3.2b.4F 的 Step0 Save→Step1 入口、G3.2b.5B 的 Patch 下拉。

1. **Overlay 与 Fusion 切换**：两种模式下画面都只在 ROI 轮廓内，通道颜色/权重正常。
2. **Intensity 与权重**：改窗宽窗位、改权重、显式设 0 权——画面随之变化且不越界。
3. **首次启用一个新的 cuCIM 通道**：一次完整清晰出现（不先糊后清），随后平移/缩放无空洞。
4. **Patch 与 Tissue**：P8 以后的 Patch 从下拉选中并正确空降；Patch A→B→A 热返回即时。
5. **离开 Step1 再回来、切换 ROI、再 Save 一次**：画面与轮廓都跟着新 ROI，不残留旧边界。
6. **关闭 Step1 / 退出**：无卡死、无残留进程。
7. **（可选）GPU 不可用时**：确认 CPU 回退仍能显示（此时**没有**多边形裁切，属已知限制）。
