# 部署场景与性能验收介质（长期有效；用户 2026-10-15 裁定）

## 场景
| 场景 | 存储 | 说明 |
|---|---|---|
| 边缘计算 | **雷电（Thunderbolt）接口外接固态盘** 为主 | 以后边缘计算的主要形态 |
| 服务器 | **机械硬盘** 为主 | 服务器多数仍是机械盘 |
| 当前开发机 | 机械盘（数据盘 ST18000NM000J / ST8000NM017B），另有 NVMe 固态盘 `/nvme0n1p1` | 开发与测量用 |

## 对开发和验收的要求
- **两种介质都要达标，都要和 Odon 比。** 看图性能的测量与验收：以固态盘为主（边缘计算），同时必须在机械盘上测，并和 Odon 在同一份数据、同一块盘上对比（服务器）。
- 测量时记录每个配置实际读取的数据在哪块盘上（挂载来源），一份测量里不要混用介质。
- 设计取舍不能只照顾一种介质：例如"每块一个文件"的存储（zarr）在固态盘上快、在机械盘上因寻道而慢；"一个文件里连续分块"（TIFF 金字塔）在机械盘上明显更好（R7c 第 1 步实测，`/sda1/Fusion/a9_bench/r7c/R7c1_results.md`）。
- 外接固态盘经雷电接口，带宽和延迟可能低于内置 NVMe；正式验收以实际外接盘或保守参数为准（待有设备时补测）。
