## 3. 核心身份与版本（贯穿各段）
- **位置身份**（在同一份对应表快照内稳定）：`(slide_id, map_sheet 指纹, position_id)`，空位也有位置身份；换一份对应表文件即为新的身份集合（不另造身份系统）。核心标签（如 `X3-Y07`）与供体编号是位置身份的属性。
- **几何**：锁定时写成区域（`type="TMA_core"`，`region_id` 由几何按 A3 规则生成）。几何一改即新 `region_id`；空位无 `region_id`。
- **锁定版本**同时冻结：对应表（文件指纹与解析结果）、方向与编号、样本映射、各核心几何、所用去阵列版本、用户确认记录。之后任何修改生成新版本；**历史运行永远引用其当时的版本**，不因当前映射改变而重新解释旧细胞结果（A3 / A4 身份约定，`docs/v16_A3A4_application.md:193`）。
- 核心表 `tma_cores.parquet`（按锁定版本存，键 = 位置身份；列：region_id（可空）、标签、行列、供体、状态候选标记、几何、版本）；**不改** `regions.parquet` 固定结构。
- **区域交给现有流程**：锁定时把该版本的核心区域写入工作区 `roi_config.json`（现有对象表构建器 `core/object_tables.py:255` 与各步骤从这里读区域），核心表另存，按 region_id 关联。
- **历史运行按其自身版本解析**：TMA 运行记录其锁定版本；历史 TMA 运行的区域身份、几何与样本映射一律按该版本解析，当前 `roi_config.json` 只代表当前版本。现有按当前工作区解析区域的消费者（`core/object_tables.py:170` `build_cells`、`core/provenance.py:480` Step4 出处登记）在 TMA 工作区中改为按运行的锁定版本解析（纳入 F4 白名单；不改固定 Parquet 结构，不扩展通用 registry）。验收含"改轮廓 / 改映射后读取旧结果"。

## 4. 分段（顺序符合 v2.3 §10：Foundation → 去阵列 → 手工校正 → 身份映射锁定；QualityMask 在本期之后）
### F1 研究清单与对应表（无界面）
- 新模块 `core/tma/`：`map_sheet.py`（openpyxl 解析与**严格校验**）、`study.py`（研究清单 `tma_study.json`）、`cores.py`（核心表读写）。
- 校验区分三类：**布局位置**（Information 声明的行列与网格一致、编号公式；解析器对任意行列通用，19 × 8 是四份 TMA138 的验收尺寸）、**已占用位置**（RB_1 / RB_1_Donor / Lookup 中有供体的位置，三者编号与供体一致）、**可选字段**（Spot Slide 有则核对 `列_(行;列)`，无则跳过；位置 1 可无）。不一致即报错并指出位置。表载核心数不当作图上必能检出的核心数。
- 新增 artifact kind `tma_map_sheet`（改 `core/provenance.py` 的 KINDS 允许列表）。
- 验收：四份表全部通过；人为改坏（重复编号、缺供体、行列错位、网格尺寸不符）各自报错；单元测试。
### F2 去阵列与方向判定（无界面）
- `core/tma/dearray.py`：低分辨率 DAPI 前景（TMA 专用参数，单独记录输入通道、层级与参数；不沿用 `core/random_patches.tissue_mask` 为整块组织调的参数；坐标换算复用 A3 的 `SlideFrames`）→ 候选核心（连通域；只对粘连候选用分水岭）→ 形状量（面积、圆度、等效半径、贴边、组织量）→ 网格拟合（稳健仿射，允许缺失、破碎）。
- **方向判定**：枚举 8 种摆放（4 种旋转 × 是否翻面；这是图像摆放变换，表内编号公式不变——四份表均逐列同向编号，蛇形不作为合法候选，只在拟合异常时作诊断提示）；用两个锚点（故意留出的空位、最后两个 Tonsil）限定，再以"同一供体的核心彼此相像"（纹理 / 强度特征的组内一致性）打分；位置 1 对照用于复核。"同供体相像"只作辅助评分，不作身份真值；锚点（空位、Tonsil）的图像识别本身需验证，138.2 只有 1 个空位，更易受组织脱落或漏检影响。输出最佳与次佳方向及分差；证据不足时明确标"待确认"，供 F3 确认。
- 状态（present / empty / folded / fused / edge-truncated / low-tissue）**只是候选标记**，不作科学排除，不进对象表。
- 结果为去阵列 artifact（新增 kind `tma_dearray`），带版本；**不写区域**。
- 验收：Slice1 上与用户确认的方向一致（180°，每列自下而上）；以人工标注的图像对应关系为准，报告遗漏、误配、待确认；其余三张报告方向判定与定位结果。不以"凑够 N 个"为通过条件。
### F3 TMA 页面：方向确认、手工校正、锁定（新界面）
- **2026-10-17 调整（用户裁定，见 `docs/tma_f3_page_application.md` 第四版）**：编号改为 9 月规范（`docs/tma_core_editing_and_mapping.md`）的分段拖线 / 连续点击 / 单颗编号，由用户指定顺序，方向在逐段确认中处理；不做"拆"、要做"并"；写 `roi_config.json` 推迟到 F4（F3 只存锁定版本）。下面原文保留作历史。
